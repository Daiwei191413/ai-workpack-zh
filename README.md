# 中文精选工作包

从 agency-agents 提炼、改写的六类中文工作方法：仓库分析、最小修改、代码审查、证据验收、技术写作、项目交接。

适合配合能够读取项目文件的 AI 助手使用。资料为 Markdown，无需安装插件，不自动运行代理或加载到新聊天。

## 开始使用

下载或克隆本仓库到本地。Windows 建议放在 D:\Codex\Projects\中文精选工作包；保存前检查已有同名目录并复用。

在能读取此目录的聊天中发送：

```text
请读取本工作包中的 工作规则.md，按任务路由执行。
目标仓库或项目：【填写 GitHub 仓库链接或本地路径】
本次任务：【分析、修复、审查、验收、写文档或继续项目，并说明具体目标】
交付位置：【填写 D 盘绝对路径】
请完成任务，以实际文件和验证结果说明结论。
```

如果助手无法定位本工作包，请提供 工作规则.md 的本地绝对路径。普通网页聊天若没有文件访问能力，可粘贴工作规则与对应角色正文。

[开始使用与更多指令](开始使用.md) 中的“工作包本地目录”和“D盘交付目录”需要替换为你实际使用的路径。

## 使用边界

角色是任务指导，不代表独立训练模型或专业资质。工具执行、账号权限和联网能力由宿主提供。示例是源码评估，不构成业务效果或运行兼容性认证。保持用户授权范围，避免把示例命令当已验证结果。

本包保留 D 盘交付约定；其他操作系统用户应在任务中明确实际存储目录。资料不自动跟随上游更新。
